📦 INSTALLATION & STARTUP

On Windows:
  1. Double-click "start.bat"
  2. Wait for dependencies to install (first run only)
  3. Browser will open to http://localhost:3000

Manual Start:
  1. Open Command Prompt in this folder
  2. Run: npm install  (first time only)
  3. Run: npm start
  4. Open http://localhost:3000 in browser

1. TEXT-TO-SPEECH
   • Enter any text
   • Choose from recommended voices
   • Select an emotion (Excited, Sad, Calm, etc.)
   • Generate audio instantly

2. VOICE CLONING
   • Clone your own voice
   • Use your cloned voice for TTS
   • Provide 1-5 audio sample URLs (10-60 seconds total)

3. AUDIO MANAGEMENT
   • Play generated audio in browser
   • Download as MP3 file
   • Copy audio URL to clipboard
   • Check remaining API credits

🔧 TROUBLESHOOTING

Problem: "Port 3000 already in use"
Solution: Edit .env and change PORT to 3001, 3002, etc.

Problem: "Failed to load voices"
Solution: Check API key in .env file is correct

Problem: "No audio generated"
Solution: Ensure text is entered and voice is selected

Problem: "Module not found error"
Solution: Run "npm install" in command prompt

For more help, see README.md
